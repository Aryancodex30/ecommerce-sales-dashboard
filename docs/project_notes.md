# Project notes

This project is designed as a practical data analyst portfolio piece. It sits between a beginner SQL assignment and a real consulting-style dashboard project.

## Recommended narrative for GitHub or LinkedIn
"Built an e-commerce sales dashboard and analytics project to evaluate revenue, customer value, product performance, and fulfillment. The work includes a relational schema, KPI analysis in SQL, Python-based cleaning and analysis, and a dashboard specification for executive reporting."

## Example extension ideas
- Add churn prediction with logistic regression
- Forecast revenue by category monthly
- Add product recommendation analysis based on basket data
- Build cohort analysis for retention
- Extend to marketing campaign ROI analysis
