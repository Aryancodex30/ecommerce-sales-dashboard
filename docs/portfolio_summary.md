# Productized portfolio summary

## Project title
E-Commerce Sales Dashboard: Revenue, Product, and Customer Insights

## Problem statement
The business needs a clearer view of product performance, customer value, and operational efficiency. Without a single dashboard, teams make decisions using fragmented reports and limited visibility into sales trends.

## Approach
I built a retail analytics project using an e-commerce schema, transactional data, and SQL-based analysis. I then extended the work with Python data cleaning, customer segmentation, and forecasting to provide both operational and strategic insights.

## Deliverables
- Relational database schema for sales and product data
- SQL queries for revenue, product, customer, order, and geographic analysis
- Python scripts for data preparation and exploratory analysis
- Customer segmentation using RFM-style logic
- Forecasting and dashboard export outputs
- Dashboard wireframe for a business-ready Power BI/Tableau report

## Key findings
- Premium customers drive the highest lifetime value
- A small number of product categories contribute most revenue
- Fulfillment delays and return reasons impact customer satisfaction and margin
- Some regions show stronger conversion and profitability than others

## Business impact
This project shows how data analysis can answer real questions:
- which products to prioritize
- where to invest marketing spend
- how to reduce return rates
- where operational bottlenecks exist

## Skills demonstrated
- SQL analytics and data modeling
- Python for ETL and analysis
- Business KPI analysis
- Customer segmentation
- Visual dashboarding and storytelling
- Portfolio-ready reporting
